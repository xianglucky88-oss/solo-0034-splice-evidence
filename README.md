# 纤证 · 接续损耗交接台

纤证把光缆接续验收的计划、双端仪表事件和签发证据放在一个本地工作台。验收人员可以查看每个测量事件怎样定位到设计接续点，核对两端有符号损耗和链路闭合差，并导出指定签发修订的留档材料。

## 运行

在仓库根目录运行。服务使用 Python 3.9+ 标准库和 SQLite，浏览器使用原生 HTML、CSS 与 ES Modules，无需安装应用依赖。

```bash
python3 -B -m splice
```

打开 `http://127.0.0.1:8734/`。数据库默认写入 `splice-evidence.sqlite3`。也可在启动时指定数据位置和端口。

```bash
python3 -B -m splice --db ./example.sqlite3 --port 8740
```

## 演示

1. 点击「导入演示」。工作台会登记光段计划、收件三份仪表凭证，并采用 A-105 与 B-203。原始样例可在 `examples/` 下查看。
2. 查看「双端里程对照」，点击 J01 的 A7，核对原始第 1 行、仪表里程 373 米、统一里程 363 米和有符号损耗 −0.030 dB。J01 的双向损耗为 0.045 dB。
3. 点击「签发当前修订」，打开签发记录中的 JSON 或接续点 CSV。每个版本保留签发时的损耗和两端凭证引用。
4. 返回当前修订，将乙端凭证切换到 B-204 并签发新修订。在签发记录中比较两次签发的点位与链路差值。

```bash
# 临时 SQLite 中的 HTTP 演示验收，完成后清理数据
python3 -B -m tools.smoke
# 源码语法及 DDL 检查，需要 Node.js 命令行
python3 -B -m tools.check_source
# 换版、拆并分组对账与版本扫测隔离的端到端验收
python3 -B -m tools.smoke_versions
```

## 计划换版与跨版对账

北岸桥改线一类的工程变更以**计划版本**登记。启用新版时需要现行计划依据、完整新点位，以及逐点确认的 `split`（拆）、`merge`（并）、`continue`（沿用）、`added`（新增）、`retired`（退役）关系；两版每个点位恰好归入一项。沿用关系必须沿用原判限，依据过期、漏项或冲突时原计划与采用保持不变。

- 每个版本独立收件双向扫测。新版只采用本版扫测，迟到的旧扫测即使恢复原窗也会被拒收；各版独立采用、独立签发，旧签件按原摘要读回。
- 跨版对账任选两件签件，按确认关系把点位分组：每件点位各计一次，列两侧点位、损耗合计与差额；退役、新增点进单侧组。同号点不自动对齐。
- 中间版本可未签，其点位只作关系链证据。首末对账的拆并组只呈现首版点与末版合并点，可追两次变更与两件观测；一支延续、一支退役时延续支独立成对、退役支单列。
