# 纤证 · 接续损耗交接台

纤证把光缆接续验收的计划、双端仪表事件和签发证据放在一个本地工作台。验收人员可以查看每个测量事件怎样定位到设计接续点，核对两端有符号损耗和链路闭合差，并导出指定签发修订的留档材料。

## 运行

在仓库根目录运行。服务使用 Python 3.9+ 标准库和 SQLite，浏览器使用原生 HTML、CSS 与 ES Modules，无需安装应用依赖。

```bash
python3 -B -m splice
```

打开 `http://127.0.0.1:8734/`。数据库默认写入 `splice-evidence.sqlite3`。也可在启动时指定数据位置和端口。

```bash
python3 -B -m splice --db ./example.sqlite3 --port 8740
```

## 演示

1. 点击「导入演示」。工作台会登记光段计划、收件三份仪表凭证，并采用 A-105 与 B-203。原始样例可在 `examples/` 下查看。
2. 查看「双端里程对照」，点击 J01 的 A7，核对原始第 1 行、仪表里程 373 米、统一里程 363 米和有符号损耗 −0.030 dB。J01 的双向损耗为 0.045 dB。
3. 点击「签发当前修订」，打开签发记录中的 JSON 或接续点 CSV。每个版本保留签发时的损耗和两端凭证引用。
4. 返回当前修订，将乙端凭证切换到 B-204 并签发新修订。在签发记录中比较两次签发的点位与链路差值。

## 中途标记

计划可加设 `marks_mm`（实地里程数组）。凭证提供对应的 `marks_mm`（仪表读数数组）：甲向按实地升序、乙向按实地降序与计划标记一一对应。换算沿甲端起点分段线性，相邻标记之间等仪表位移对应等实地位移。缺少应有标记、多报标记或读数乱序时该向留置，不参与归点；未加设中间标记的光段继续使用近远端两点换算。

```json
{"marks_mm": [400000, 900000]}
```

```json
{"trace_id": "A-105", "direction": "a", "near_mm": 10000, "far_mm": 1610000, "marks_mm": [395000, 905000], "total_mdb": 850, "events": []}
```
