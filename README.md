# 纤证 · 接续损耗交接台

纤证把光缆接续验收的计划、双端仪表事件和签发证据放在一个本地工作台。验收人员可以查看每个测量事件怎样定位到设计接续点，核对两端有符号损耗和链路闭合差，并导出指定签发修订的留档材料。仪表可按分贝或毫分贝上报含小数的损耗，系统在收件时精确换算到半毫分贝网格，并为只收整数毫分贝的交割台账生成可追溯的入账明细。

## 运行

在仓库根目录运行。服务使用 Python 3.9+ 标准库和 SQLite，浏览器使用原生 HTML、CSS 与 ES Modules，无需安装应用依赖。

```bash
python3 -B -m splice
```

打开 `http://127.0.0.1:8734/`。数据库默认写入 `splice-evidence.sqlite3`。也可在启动时指定数据位置和端口。

```bash
python3 -B -m splice --db ./example.sqlite3 --port 8740
```

## 演示

1. 点击「导入演示」。工作台会登记光段计划、收件三份仪表凭证（混用 dB 与 mdb 写法），并采用 A-105 与 B-203。原始样例可在 `examples/` 下查看。
2. 查看「双端里程对照」，点击 J01 的 A7，核对原始第 1 行、仪表里程 373 米、统一里程 363 米和有符号损耗 −0.030 dB。J01 的双向损耗为 0.045 dB。
3. 查看点位表的「整数交割」列与摘要卡：每笔原读数旁标注入账值，含半毫读数时可看到取整方向。
4. 点击「签发当前修订」，打开签发记录中的 JSON、接续点 CSV 或交割 CSV。交割 CSV 逐点保留原读数与入账值，并给出每向点位合计、整段实测和闭合指标。
5. 返回当前修订，将乙端凭证切换到 B-204 并签发新修订。在签发记录中比较两次签发的点位与链路差值。旧签件可按其 SHA-256 摘要通过 `/releases/by-digest/{digest}` 查回。

凭证重传按去单位后的规范内容识别：同号同内容仅换写 dB/mdb 仍算重传，改数值、方向、标记、事件或行序则返回冲突；无法精确表示到半毫分贝网格的读数（如 100.25 mdb、0.0456 dB）在收件时拒收。

# 源码语法及 DDL 检查，需要 Node.js 命令行
